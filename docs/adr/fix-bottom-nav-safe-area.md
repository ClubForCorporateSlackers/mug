- 作業の内容：下のタブ（`BottomNav`）の下の余白が広すぎたのを直す
- 進捗表のID：—
- 期間：2026-11-19 〜 2026-11-19
- 記録した者：Claude Code

## 判断：下のタブの下の余白は「8px かホームバーの高さの大きいほう」にする（足し算にしない）

- 状態：提案（人の確認待ち）

### 状況（何に迷ったか）

田中の指摘（11/19）：ナビゲーションバーの下の余白が広くなった。

fix/ios-hig（#30）で、`BottomNav` の下の余白を `pb-safe-2`（8px＋ホームバーの高さ）にした。iPhone ではホームバーが約34px あるので、ラベルの下が「ボタンの 8px＋タブの 8px＋34px」で約50px になっていた。

### 決めたこと

- `BottomNav` だけ `pb-[max(0.5rem,env(safe-area-inset-bottom))]` にした。ホームバーのある iPhone では 34px、ない端末では今までどおり 8px になる（ラベルの下は約42px）
- 下にボタンがあるページと、下から出るシートは、`pb-safe-*`（足し算）のままにした

### 理由

- iPhone の標準アプリのタブバーは、ホームバーのすぐ上に置かれ、ラベルの下の余白はほぼホームバーの分だけ。タブバーそのものは押す場所ではないので、ホームバーの分の余白に重ねてよい
- ページの下のボタンは、ホームバーのすぐ上に来ると押しにくく、ホームバーを触ってしまうので、足し算のままにする

### ほかの案

- `pb-0`＋ホームバーの分だけにする（`pb-[env(safe-area-inset-bottom)]`）：ホームバーのない端末で、ラベルの下が 8px（ボタンの分）だけになり、詰まって見える

### 影響・あとで見直すこと

- iPhone の実機では確かめていない。ホーム画面から開いたとき（PWA）と、Safari でツールバーが縮んだときに、ラベルがホームバーに近すぎないかを見てほしい
