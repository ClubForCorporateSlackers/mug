## 判断：自前の BottomSheet の中身を shadcn/ui の Drawer（vaul）にした

- 状態：提案（人の確認待ち）

### 状況（何に迷ったか）

田中の指摘（11/19）：ピンを押したときのハーフモーダルが、外側を押すことでしか閉じられない。shadcn のモーダルの部品を使ってはどうか。今の `BottomSheet` は自前で作った部品で、frontend/AGENTS.md の「shadcn/ui にある部品を一から書かない」にも合っていなかった。

### 決めたこと

- `npx shadcn add drawer` で `src/components/ui/drawer.tsx` を追加した（新しい依存：`vaul`）
- `BottomSheet` の中身を Drawer に置き換えた。使う側（ピンの詳細・リアクションを送る・ランキングの絞り込み・確認のシート）の呼び方は変えていない
- 閉じ方：下に引っ張る（はじく）・外側を押す・Esc キー。上の取っ手は Drawer の標準のものを使い、自前の取っ手は外した
- 読み上げ用に、シートの名前（`label`）を見えない見出し（`DrawerTitle`）にした

### 理由

ハーフモーダルは iPhone では「下に引っ張って閉じる」のが当たり前で、Drawer はそれが標準で入っている。Sheet（Radix の Dialog）は引っ張って閉じられない。

### ほかの案

- shadcn の Sheet（下から出す）：引っ張って閉じられないのでやめた
- 自前の部品に「×」ボタンを足す：shadcn にある部品を一から書かない約束に反するのでやめた

### 影響・あとで見直すこと

- 外側の暗い色が、前（`foreground` の30%）より少し濃い（Drawer の標準の黒50%）。`ui/` のファイルは書き換えない約束なので、そのままにした
- 閉じるときは、親がシートをすぐに消すので、閉じる動き（アニメーション）は短く見えることがある
