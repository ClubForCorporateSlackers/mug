- 進捗表のID：なし
- 期間：2026-11-19 〜 2026-11-19

## 判断：ボタン用の基本コンポーネントを5つに分けた

- 状態：提案（人の確認待ち）

### 状況（何に迷ったか）

ページの生のボタンは見た目が6種類ほどあり、どこまでまとめるかは指示に書かれていなかった。

### 決めたこと

- `RoundIconButton`：地図の上の白い丸のアイコンボタン（マイページ・現在地へ）
- `PillButton`：位置情報オフの帯の「許可する」
- `LinkButton`：赤い文字だけのボタン。`back` で「<」を付け、`small` で小さい文字（MePage の「< マップ」と LoginPage の「パスワードをお忘れですか？」で共用）
- `FilterChip`：ランキングの「月」「地域」（右に「∨」、左にアイコンを付けられる）
- `RankTypeTabs`：ランキングの「人／市町村／血液型」の切り替え（shadcn の Tabs）

ScreenHeader の「戻る」は枠つきで大きさも違うので、RoundIconButton にまとめず、中で Button を直接使った。

### 理由

見た目が違うものを1つの部品に詰めると props が増えて分かりにくくなるため。見た目が同じ2つ（「< マップ」と「パスワードを〜」）だけ LinkButton にまとめた。

### ほかの案

- 全部を1つの部品にして `variant` で切り替える：props が多くなり初心者に分かりにくい
- PillButton を FilterChip にまとめる：色（muted と card）と役割が違うのでやめた

### 影響・あとで見直すこと

同じ見た目のボタンをほかの画面で作るときは、これらを使い回す。

## 判断：ランキングの一覧を Tabs の中身（タブパネル）に入れた

- 状態：提案（人の確認待ち）

### 状況（何に迷ったか）

shadcn の Tabs（Radix）はタブに `aria-controls` を付ける。中身（TabsContent）がないと、指す先のない属性になる。

### 決めたこと

`RankTypeTabs` に `children` を渡せるようにし、TabsContent の中に出す。RankingPage は「答えない」のお知らせ・エラー・ランキングの表を `RankTypeTabs` の中に入れた。間隔（gap-4）は今と同じにしたので見た目は変わらない。

### 理由

読み上げソフトで「タブ」と「その中身」がつながり、今よりアクセシビリティがよくなるため。

### ほかの案

タブだけにして中身は外に置く：見た目は同じだが、指す先のない `aria-controls` が残る。

### 影響・あとで見直すこと

タブを矢印キーで動かせるようになった（Radix の動き）。矢印キーで種類を移るとすぐ読み直す。

## 判断：見た目を合わせるため、shadcn の部品に className で上書きした（小さな違いは残した）

- 状態：提案（人の確認待ち）

### 状況（何に迷ったか）

shadcn の Button（ghost・outline・link）や Tabs には、もとの生のボタンにはなかった見た目（マウスを乗せたときの色・下線、フォーカスの輪）が付いている。

### 決めたこと

- 色・大きさ・角の丸み・文字の太さは className で今と同じにした（例：Tabs の選択中の影を消し、背景を `bg-card` にした）
- マウスを乗せたときの色（ghost は `bg-accent`、link は下線）とキーボードのフォーカスの輪は残した

### 理由

マウスを乗せたときの色は、Tailwind v4 ではマウスがある端末だけで効く（スマホでは押したあと色が残らない）。フォーカスの輪はキーボード操作のためにあったほうがよい。

### ほかの案

`hover:bg-card` などで全部打ち消す：クラスが増えて読みにくく、フォーカスの輪まで消すとアクセシビリティが下がる。

### 影響・あとで見直すこと

パソコンのブラウザでは、マウスを乗せると色が変わる・下線が出る。気になれば基本コンポーネントの中だけ直せばよい。

## 判断：shadcn の tabs を追加したことで lint の警告が1件増えたが、そのままにした

- 状態：提案（人の確認待ち）

### 状況（何に迷ったか）

`npx shadcn add tabs` が作る `ui/tabs.tsx` は `tabsListVariants` を export するため、`npm run lint` で `react(only-export-components)` の警告が出る（`ui/button.tsx` と同じ種類）。あわせて `ui/item.tsx` が使う `ui/separator.tsx` も追加された。

### 決めたこと

coordinator に確認し、警告2件（`ui/button.tsx` と `ui/tabs.tsx`）のままにした。

### 理由

`ui/` の shadcn 生成ファイルは手で書き換えない約束で、CI の lint は警告では失敗しないため。

### ほかの案

`ui/tabs.tsx` の export を消す／Tabs を使わない：前者は約束違反、後者はアクセシビリティが下がる。

### 影響・あとで見直すこと

lint の警告は2件になる。
